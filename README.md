# 🎹 Touch Piano Using Arduino Nano and TTP223

## 📌 About the Project
This project is a simple electronic touch piano built using an Arduino Nano and TTP223 capacitive touch sensor modules. Instead of using traditional push buttons, the piano uses touch-sensitive sensors to detect finger touches and generate musical notes. Each sensor acts as a piano key, allowing users to play different notes by touching the corresponding sensor. This project combines electronics, programming, and music to create an interactive musical instrument.

## 🛠️ Components Used
- Arduino Nano
- TTP223 capacitive touch sensor modules
- Buzzer 
- Breadboard 
- Jumper wires
- USB cable 

## ⚙️ How It Works
The TTP223 sensors detect when a user touches a sensor surface and send a digital signal to the Arduino Nano. The Arduino processes these signals and generates the corresponding musical tones using its programmed logic. Each touch sensor can be assigned a different musical note, allowing the user to play melodies by touching different keys.

## ✨ Features
- Touch-based piano keys
- No traditional mechanical buttons required
- Simple and interactive design
- Arduino-based control system
- Expandable with additional touch sensors and musical notes

## 💻 Programming
The project is programmed using the Arduino IDE. The code reads the digital outputs of the TTP223 sensors and generates musical notes according to the selected key. The notes can be produced using a buzzer or another compatible sound output device.

## 🎯 Project Objective
The main objective of this project is to explore capacitive touch sensing, microcontroller programming, and basic sound generation. It is a fun DIY electronics project for learning Arduino, experimenting with touch sensors, and creating interactive musical devices.

## 🚀 Future Improvements
Possible upgrades include adding more keys, improving the sound output, creating a proper piano-shaped enclosure, and adding different musical scales or melodies.
